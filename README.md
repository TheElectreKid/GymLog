# GymLog

A simple Android app for managing gym memberships. Built with React Native and Expo.

## Features

- Add, edit, and delete members
- Automatic active/expired status based on expiry date
- Search members by name
- Dark mode support
- Export and import member data as backup
- Persistent local storage

## Getting Started

1. Install dependencies

```bash
   npm install
```

2. Start the development server

```bash
   npx expo start
```

3. For a full development build on Android

```bash
   npx expo run:android
```

## Tech Stack

- React Native
- Expo
- AsyncStorage
- Expo File System
- Expo Sharing
- TypeScript

## Requirements

- Node.js 18+
- Android device or emulator for testing
